Visiq — Autonomous AI Data Analyst Agent

A full-stack production AI platform that converts conversational natural language into deterministic data analysis, dynamic statistical visualizations, and actionable business intelligence — without hallucinating numbers.

View on GitHub ↗

Executive Summary

Visiq solves a core problem in generative AI: AI assistants hallucinate numbers when asked analytical questions about datasets. Visiq's Hybrid Agent Architecture decouples intent classification from execution — queries are routed dynamically between a deterministic Python execution sandbox, a semantic RAG retrieval engine, or a hybrid reasoning pipeline.

Built with enterprise-grade security and multi-tenancy: Supabase asymmetric JWT authentication, per-client daily token quotas (50k/day), zero-escape filesystem containment, Copy-on-Write (COW) dataset isolation, and zero-config dual persistence (SQLite local / PostgreSQL cloud).

System Architecture

Client Layer — React 18 + Vite + Tailwind v4
App Dashboard, Streaming Chat Canvas, Plotly Visualization Engine, Live Dataset Editor (COW), Pinned KPI Dashboard Widgets, Supabase Auth Modal.
Enterprise Security Perimeter
Vite Dev Proxy / NGINX → RequestBoundary Middleware (5MB limit, request IDs) → Supabase Auth Guard (RS256 JWKS) → Daily Token Quota Guard (50k / atomic metering).
FastAPI Core Engine — Python 3.14
Async API routes: /api/chat/ask (stream), /api/datasets, /api/widgets, /api/user/quota. Pydantic validation throughout.
Autonomous Agent Coordinator
LLM + Heuristic Intent Router → Structured Engine (Pandas sandbox), RAG Engine (TF-IDF retrieval), or Hybrid Engine → Chart Tool Spec Synthesizer (Bar, Line, Pie, Scatter, Heatmap, Box, Area).
Persistence & Storage Layer
SQLAlchemy 2.0 (SQLite local / PostgreSQL prod) + Secure Storage Vault (path containment + COW sandbox).
Inference Providers
Groq API (Llama 3 — sub-second) + Google Gemini 2.5 Flash (deep reasoning). Hot-swappable at runtime.

Enterprise Security Hardening

Path Traversal Guard
Eliminates directory traversal attacks, null-byte injections, absolute path overrides, and Windows device name abuse (CON, PRN, AUX, NUL).
Bounded Request Streaming
Custom Starlette middleware caps request bodies at 5MB before JSON deserialization, mitigating memory exhaustion DoS vectors.
Asymmetric JWKS Verification
Supabase RS256 JWT signatures validated via remote JWKS caching with local development mock fallback.
Credential-Safe Logging
Structured JSON logs with unique request correlation IDs (x-request-id) while stripping credentials, authorization headers, and API keys.
