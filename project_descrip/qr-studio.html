QR Studio — Modern QR Code Generator

A polished Python desktop application for generating, styling, previewing, and exporting professional QR codes across six purpose-built content types.

View on GitHub ↗

Executive Summary

QR Studio turns the usually utilitarian QR-generation workflow into a focused desktop experience. Its dark-slate interface combines real-time debounced previews, curated color palettes, custom branding, and high-resolution exports without blocking the Tkinter event loop.

The application supports URLs, WiFi credentials, vCards, email, SMS, and plain text. A modular Python architecture separates content formatting, QR generation, UI state, and session history so every saved item can restore its complete configuration in one click.

Application Architecture

Desktop Shell — Python + Tkinter
The main application controller manages layout, state, keyboard shortcuts, validation feedback, and the dark-slate design system.
Content-Type Input Layer
A segmented interface exposes purpose-built forms for URL, WiFi, vCard, email, SMS, and note payloads without overwhelming the user.
Payload Formatting Utilities
Dedicated helpers sanitize URLs and serialize standards-compliant WiFi, vCard 3.0, mailto, and SMSTO payloads.
QR Generation Engine
The qrcode library builds the matrix while Pillow handles recoloring, scaling, captions, protective masks, and centered logo compositing.
Preview & Export Pipeline
Debounced rendering keeps the UI responsive; finished codes can be exported as PNG or JPEG or copied directly to the Windows clipboard.
Session History & Restoration
Recent-history cards retain thumbnails, metadata, visual settings, the active content type, and every form field for exact restoration.

Key Features

⚡
Live Debounced Preview — Rebuilds the QR code as settings change while preventing rapid input from freezing the desktop interface.
🎨
Professional Styling Controls — Six presets, custom foreground and background colors, four output sizes, captions, and adjustable error correction.
🖼
Logo-Safe Composition — Embeds PNG, JPG, ICO, or WebP logos with a protective boundary mask and automatically upgrades recovery strength.
📱
Six Content Types — Dedicated forms produce correctly structured URL, WiFi, vCard, email, SMS, and plain-text payloads.
🗂
Restorable Session History — Visual history cards can restore the exact form values, palette, size, correction level, label, and active tab.
⌨
Fast Desktop Workflow — Generate, save, or copy through keyboard shortcuts, with direct image clipboard support on Windows.

Encoding & Export Details

Adaptive Error Correction
Choose L, M, Q, or H recovery levels; logo embedding automatically selects stronger correction to preserve scan reliability.
Standards-Ready Payloads
Formatting helpers generate vCard 3.0, WiFi configuration, mailto, and SMSTO strings from friendly form inputs.
Flexible Resolution
Export at 150, 300, 450, or 600 pixels to match quick sharing, print materials, and presentation needs.
Cross-Format Branding
Pillow handles custom colors, captions, centered logos, safe resizing, and consistent PNG or JPEG output.
